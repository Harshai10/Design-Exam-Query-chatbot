# Design-Exam-Query-chatbot
This project is a chatbot designed to provide answers to design exam-related queries. The chatbot uses natural language processing (NLP) and machine learning algorithms to fetch relevant responses from a blog named Stuff You Look (SYL).


Features

  Design Exam Preparation: The chatbot provides detailed suggestions, tips, strategies, steps, ideas, and solutions for design exam preparation.
  
  Query-based Response: The chatbot responds to user queries based on the content of the SYL blog.
  
  Link to SYL Blog: The chatbot provides a link to the SYL blog so users can access more information.

  
Technical Details

  Language: The chatbot is built using Python.
  
  Libraries: The chatbot uses the following libraries:
  
    Streamlit for the user interface
    
    OpenAI for natural language processing and machine learning
    
    FAISS for efficient similarity search
    
    Data: The chatbot uses a dataset of scraped text from the SYL blog.
